## About Me

I'm a **Full-Stack Software Engineer and Technical Lead** focused on building software that is scalable, maintainable, reliable, and ready for real-world production.

My work covers the complete engineering lifecycle:

<div align="center">

`Requirements` → `Architecture` → `Database` → `Backend` → `Frontend` → `Deployment` → `Optimization`

</div>

I primarily work with **TypeScript, Next.js, React, Node.js, NestJS, PostgreSQL, MongoDB, Prisma, and Redis**.

My strongest engineering interests are:

* Backend architecture and API design
* System and database design
* Authentication and authorization
* Complex business workflows
* Performance and scalability
* Production infrastructure
* Technical leadership and engineering standards
